C4CNN001 — compact Connect Four value + policy network

Architecture as implemented in research/az-train/src/az_train/convnet_c4.py. Inference-only NumPy; deterministic Adam fit on self-play outcomes (value) and completed-Q targets (policy).

Shared trunk Value head Policy head Inference wrapper

Fixed hyperparameters

  • Board 6 × 7, input 2 planes (side-to-move occupancy, opponent occupancy)
  • CHANNELS = 16 throughout the trunk, BLOCKS = 2 residual blocks
  • VALUE_HIDDEN = 32, POLICY_OUTPUTS = 7
  • All convolutions use zero padding; 3×3 in the trunk (pad 1, shape-preserving), 1×1 projections in each head (pad 0)
  • Serialized as C4CNN001: <8s9I header then N_WEIGHTS little-endian float32

Training notes

  • Loss = value_loss_weight · value MSE (tanh output vs self-play outcome) + masked policy cross-entropy over legal columns + L2 on weight tensors
  • Deterministic Adam (β₁=0.9, β₂=0.999), seeded shuffle, early-stop checkpoint chosen by highest held-out value Pearson
  • Per-epoch diagnostics: shared-trunk value/policy gradient cosine (head conflict), ReLU activation health, orientation (literal vs mirror-averaged) metrics
  • A structurally mirror-equivariant value variant also exists (fit_equivariant_value_policy / _predict_value_equivariant): both orientations pass through the shared trunk, every feature map is column-symmetrized and averaged before a single value head, making the scalar exactly mirror-invariant for any weights. The policy head there still reads the literal trunk.
